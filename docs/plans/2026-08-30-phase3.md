# Vukovica Phase 3 Implementation Plan — The Revamp

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove all runtime AI; add letters deck, capture queue, books (photo upload), grammar drills, XP/progress; switch UI to English; seed Claude-authored content; deploy.

**Architecture:** Pure client + Supabase (RLS, RPCs, storage). All AI-era Edge Functions deleted. Content pre-authored into `data/phase3/` by a content agent (runs in parallel, touches only that directory) and seeded via SQL/scripts. One local batch script generates audio with a free TTS (Piper, espeak-ng fallback).

**Tech Stack:** unchanged (Expo SDK 54, expo-router, supabase-js, ts-fsrs, vitest). NEW: expo-image-picker (books), Piper TTS (local tooling only, not an app dep).

**Spec:** `docs/specs/2026-08-30-phase3-revamp.md` — READ FIRST; §ref numbers below point there. MVP/Phase-2 conventions carry over (explicit grants, SECURITY INVOKER RPC pattern, prompt-free codebase after removals, browser verification with dev user mark@local.dev / vukovica-local-dev).

## Global Constraints

- Branch `mvp`, sequential tasks, `npm test` + `npm run typecheck` green at every task end; conventional commit per task.
- ALL user-facing copy in English (spec §3). Serbian only as learning content. No Cyrillic in chrome.
- Every new table: owner-only RLS + explicit grants to authenticated + revoke anon (haven pattern, as existing migrations). RPCs: SECURITY INVOKER, auth.uid(), grant execute to authenticated, revoke PUBLIC/anon.
- Latin is always DERIVED via `cyrToLat` — never stored for content; `accepted` grammar answers compare via `latToCyr` (spec §9).
- XP awards verbatim (spec §10): review 2, trainer round 10, grammar run 15, story finish 20, book finish 50. Level = 1 + floor(total/150). Daily goal 30 XP, local-day semantics identical to streak.
- Stage names/goals verbatim spec §10; stages stay SOFT.
- `data/phase3/` is owned by the content workstream — implementation tasks read from it but never write it.
- No new Edge Functions; no runtime network calls except supabase-js.

### Task 1: Schema migrations + types

**Files:** Create `supabase/migrations/<ts>_phase3_schema.sql`; Modify `lib/types.ts`.

**Interfaces (produces, later tasks consume verbatim):**
- `cards.kind text not null default 'word' check (kind in ('word','letter'))`; `cards.audio_path text` (nullable).
- `books` (id uuid pk default gen_random_uuid(), user_id uuid references auth.users not null, title_en text not null, title_cyr text, status text not null default 'pending' check (status in ('pending','ready')), source text not null check (source in ('claude','photos')), finished_at timestamptz, created_at timestamptz default now()).
- `book_pages` (id uuid pk default gen_random_uuid(), book_id uuid references books on delete cascade not null, user_id uuid references auth.users not null, page_no int not null, text_cyr text, photo_path text, created_at timestamptz default now(), unique(book_id, page_no)).
- `requests` (id uuid pk default gen_random_uuid(), user_id uuid references auth.users not null, text_en text not null, source text not null default 'typed' check (source in ('typed','reader')), status text not null default 'pending' check (status in ('pending','done')), card_id uuid references cards, note text, created_at timestamptz default now(), done_at timestamptz).
- `grammar_topics` (id uuid pk default gen_random_uuid(), slug text unique not null, title_en text not null, explain_md text not null, sort int not null) — global content: RLS enabled with SELECT-for-authenticated policy, no user_id; INSERT/UPDATE/DELETE not granted to authenticated.
- `grammar_items` (id uuid pk default gen_random_uuid(), topic_id uuid references grammar_topics on delete cascade not null, prompt text not null, answer_cyr text not null, note text, sort int not null) — same global-content policy.
- `grammar_stats` (user_id uuid references auth.users, topic_id uuid references grammar_topics, attempts int not null default 0, correct int not null default 0, updated_at timestamptz default now(), pk (user_id, topic_id)) — owner RLS.
- `xp_events` (id uuid pk default gen_random_uuid(), user_id uuid references auth.users not null, amount int not null, kind text not null check (kind in ('review','drill','grammar','story','book_page','book_finish','request')), created_at timestamptz default now()) — owner RLS, INSERT+SELECT granted.
- RPC `bump_grammar_stats(p_topic_id uuid, p_attempts int, p_correct int)` — upsert-add on grammar_stats for auth.uid(), SECURITY INVOKER, pattern-copy of `bump_drill_stats` (read that migration first).
- Storage bucket `book-photos` (private) + owner-scoped storage policies mirroring the existing `audio` bucket policy block in the schema migration.
- TS types in `lib/types.ts`: `BookRow`, `BookPageRow`, `RequestRow`, `GrammarTopicRow`, `GrammarItemRow`, `GrammarStatRow`, `XpEventRow`; extend `CardRow` with `kind: 'word' | 'letter'` and `audio_path: string | null`.

**Steps:** read existing migrations for the grant/RLS/RPC house style → write migration → `npx supabase db reset --local` full replay + reseed + re-signup per README → types → suite + typecheck → commit `feat: phase 3 schema`.
